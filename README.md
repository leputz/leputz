### Project: Video Splitter Chrome Extension

**My role:** Full-stack engineer

**Project description:**  
The Chrome extension allows the user to upload a chosen video file on a local device. After some size checking and integrity checking mechanism, it posts the video to a back-end server, which handles the splitting based on some scene/voice detection algorithm. The back-end server is deployed with queueing and cache management for performance and reliability. Tasks are monitored to ensure auto-recovery. A scheduler is set up for automatic cleaning of long-life files generated. Processes are managed by a separate service, and the memory allowance of apps is monitored.
